# Absence — ورقة الغياب

تطبيق ويب عربي لطباعة أوراق الغياب وأوراق الدخول بالثانويات الإعدادية المغربية، مبني على لوائح منظومة **مسار**.

**رابط التطبيق:** [mohamedmorjane1-oss.github.io/absence](https://mohamedmorjane1-oss.github.io/absence/)

## أهم الأقسام

- **استيراد اللوائح:** استيراد لوائح الأقسام ومجموعات الدعم (TaRL) من ملفات مسار.
- **ورقة الغياب:** ورقة غياب نصف أسبوعية لكل قسم أو مجموعة دعم، جاهزة للطباعة أو التحميل PDF.
- **ورقة الدخول:** 14 ورقة دخول في كل صفحة A4.
- **الإعدادات:** ترويسة الوثائق واسم المؤسسة والمدينة.

## الاستعمال

- يعمل على الهاتف والحاسوب مباشرة من المتصفح.
- يمكن تثبيته على الهاتف كتطبيق بأيقونته (من قائمة المتصفح: «إضافة إلى الشاشة الرئيسية»).
- يعمل دون إنترنت بعد أول فتح.

## حماية المعطيات

بيانات التلاميذ تُحفظ في جهاز المستعمل وحده، ولا تُرسل إلى أي خادم.
